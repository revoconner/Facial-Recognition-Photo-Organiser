Felicity is the offline, privacy focused and ease of use focused, facial recognition photo organizer for Windows. It finds and groups every photo of the same person across your whole library, automatically.

### Announcement: New update 0.8.2 releasing within 24 hours!

A no-nonsense photo organiser for windows, if you want to group people by faces without having to deal with complex UI. 

- Really accurate in real world tests.
- User friendly UI
- No need for manual tagging, or confirming faces.
- Completely offline and built for privacy
- Just point to the location of your folders and let the app do its thing.
- Includes accessibility support for color blindness (4 distinct ones better suited to protanopia, deuteria, deuteranopia, tritanopia and complete color loss), contrast loss, including dyslexia friendly fonts etc, animation and transparency toggles.
- Has pro tools for those who need it, without cluttering the UI. Such as exporting the orgnanised folders (hardlink/copy), exporting tagged info via XMP so it's compatible with lightroom, and metadata grouping and sorting.
- Privacy focused. The app is freeto use and is completely offline, no telemetry, no ads, no subscriptions or one time payment.
- Also includes user focused privacy filters like hiding people, hiding select photos from showing up for non hidden person.
- Themeable with inbuilt GUI.
- Colors and fonts are now more readable with a completely rebuilt dark and light theme with multiple accents.

## Why doesn't this repository have any code if the app is open source?

**Short Version:** The code was removed to avoid people forking it, and implementing it in their own copycat app with the use of AI.

It's not that I have a problem with people using AI. I use AI for help as well. People using the source to adapt the tool to their needs are welcome and can still use the code. 

I have a problem with users forking to simply reskin without an ounce of work, simply using AI generated theme (**** eyesore), change the name, remove my name from the app and re upload it as their own. 

Now I know my other project and website is built with AI themes because they were made when I was sick and couldn't really sit for long on the workstation. And I know their UI but specially the UX and accessibility sucks terribly. They are being remade.

Good luck with accessibility and readability on those, It took me weeks alone to properly research the UI, and days of testing.

The license does not allow a person to do that, however, a license is only as good as the developer's power to enforce it. So as sole developer who isn't making money out of the app, I had to move the code off the platform.
The source code is still available to be viewed and scrutinised at [SOURCE CODE](https://www.github-unlisted.com/revoconner/felicity-dev/?s=64f1770d-8f52-4c66-bf1d-b42f2e840306)

The link has bot firewall enabled to make it harder for the copycats.

## Why no issues tab?

Well the app was always aimed at regular users first. And while GitHub has become second nature to use, regular everyday users don't even have an account.

By putting the "report a problem" and "request a feature" button right inside the app, that takes you to the website form, its easier for everyone to file a bug report. Clicking the inbuilt button also exports log and relevant data to the desktop, so a user just have to upload it along with describing their problems. No account or technical knowledge needed.

### Progress tracker and development cycle

A custom built kanban style board that's easy to understand, tracks bugs and features and can be viewed across versions.
